# Dr Chaithanya H. Devadiga — Physiotherapy website

Open index.html in a browser to preview. Keep all files together.

Deploy this folder as a static website. No installation or build step is needed.

All three WhatsApp contact buttons use https://wa.me/916364729452. On phones with WhatsApp installed, the link can open the app; desktop visitors can use WhatsApp Web or Desktop.

The enquiry form opens WhatsApp with a prepared message containing the entered details. The visitor reviews and sends it in WhatsApp. It does not save submissions to a database or send emails.

Files: index.html (content), style.css (responsive design), script.js (enquiry form), chaithanya-devadiga.jpg (portrait).
